The Momi Agro Industries Website is a static website built to represent the brand identity, services, and certifications of Momi Agro Industries—a company engaged in agricultural production and distribution. The site is designed to inform potential clients about the company's values, product quality, and certifications in a clean, professional layout.

It features a responsive design optimized for various devices, clear navigation, and visually engaging sections that highlight the company’s commitment to quality and sustainability. This project reflects modern front-end development practices and serves as a portfolio piece to demonstrate my skills in HTML, CSS, and JavaScript.

Whether viewed on desktop or mobile, the site offers a consistent and user-friendly experience aimed at improving the company’s digital presence.

Features :
1.Clean and responsive design
2.Home, About, Product, Certification, and Contact sections
3.Footer with social/contact info
4.Mobile-friendly layout using CSS Grid and Flexbox
5.Smooth navigation and user-friendly interface

Tech Stack:
1.HTML
2.CSS
3.JavaScript
4.VS Code for development
